scene_edit 使用 scene_edit.entities、relations、operations。target、replacement_entity 必须来自本次 entities；reference 可以是本次实体、当前/原始场景中的对象，或已注册环境引用。table、desk、desktop、桌子、桌面、台面表示已有环境支撑面，不要为了闭合引用把 table 加入 entities；只有用户明确“增加一张桌子”才创建 table。杯子、马克杯、cup、coffee cup、coffee_cup、mug 统一输出规范名 `mug`。relation/reference 必须同时存在或同时为空。场景关系使用 left_of/right_of/front_of/behind/above/below/near/on/inside；back_of、back、后面、后方归一化为 behind。普通“放到桌面上”用 on + placement_hint=any，桌面中间用 center，桌面右侧用 placement_region=right_half；左上/右上/左下/右下分别使用 left_front/right_front/left_back/right_back，不能把方向字段或距离字段混入 add 操作；Python 用确定性网格和几何证据决定是否成功。
